# Start here

You have either unzipped the session kit or opened your own project folder. Both work the same way.

1. **Open the folder in Claude Code.** Claude desktop app, Code tab, "Open folder", pick this folder. You should see a file called `START-HERE.md` (this one) and a hidden folder `.content-ops`.
2. **Place the credentials file your trainer hands you.** They tell you the exact path. It looks like `~/.content-ops/<project>/dev.env`. It never goes inside this folder. Never open it, paste it, or send it to anyone.
3. **Type your first sentence** in the chat box: *check the connection and tell me what page types we have*. Read the answer. It should say the environment and a list of page types. No write happened.
4. **Follow your trainer.** The session has eight steps. Each one is a sentence you type and a thing to look for. The take-home card in `training/` has all eight.

What to do next after the session: open `training/take-home-card.md`, and the one-page guide (`ROLLOUT.md`). The deck is linked there too; your trainer brings the PDF.

Do: read every answer before you type the next sentence.
Don't: say yes to a write unless the environment and page count on screen are what you expected.
