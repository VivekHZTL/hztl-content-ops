# Session deck

Eleven slides for the ninety-minute session: short, statement-first, meant to be shown briefly before a live demo. Published as a Slides artifact: https://claude.ai/artifact/6n2h4bms8xUT8kJRdCufWu (private until shared). Export to PDF or PowerPoint from the deck's Share menu; the trainer brings the PDF to the room.

`project/` here is the deck's own source: `deck.json` (order, sections, typefaces) and one `slides/<id>.html` per slide in the Slides format, each with speaker notes in its `<aside>`. To change a slide, edit its file and ask Claude to publish that file to the deck's address above. To regenerate the deck from scratch, give Claude this folder and the Slides type.

Order: title, no more manual authoring, your job moves up (validate, quality, strategist), driver’s seat not autopilot, it knows your project, just say it, ask it anything, mass updates, reports and sheets, three rules, let’s see it. Every demo slide quotes the exact sentence from `../session-run-sheet.md`. Nothing in the deck names a client, a person or a page that exists only on one project.
